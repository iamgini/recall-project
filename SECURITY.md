# Security

This document covers all security controls in Recall, mapped to OWASP Top 10 (2021) categories. Use it as a reference for VAPT assessments.

## Running a Security Audit

```bash
# Dependency vulnerability scan + outdated package check (no host installs)
./audit.sh
```

This builds the container image and runs `npm audit` + `npm outdated` inside it.

## OWASP Top 10 Coverage

### A01: Broken Access Control

**API key authentication** on all write operations (`POST`, `PUT`, `DELETE`). The server returns `500` if `RECALL_API_KEY` is not configured — there is no unauthenticated fallback.

- `src/index.ts` — auth middleware (line 112)
- Header: `X-API-Key`

**Secret bookmarks** are filtered from all `GET` responses unless the request includes a valid API key.

- `src/index.ts` — `isAuthenticated()` check on every read route

**Rate limiting** on write operations: 60 requests per minute per IP. Returns `429 Too Many Requests` with `Retry-After: 60` header.

- `src/index.ts` — `isRateLimited()` (line 53)
- Uses `cf-connecting-ip` on Cloudflare, falls back to `x-forwarded-for`

### A02: Cryptographic Failures

**Timing-safe API key comparison** using `crypto.subtle.timingSafeEqual`. Prevents side-channel attacks that could leak key bytes through response time differences.

- `src/index.ts` — `timingSafeEqual()` (line 21)
- Consumes constant time even when key lengths differ

**No secrets in code or git:**

| Secret | Storage |
|--------|---------|
| `RECALL_API_KEY` | `.dev.vars` (local), Cloudflare Variables (prod) |
| D1 `database_id` | `wrangler.toml` (gitignored) |
| API key (dev) | `.env` (gitignored, auto-generated by `dev.sh`) |

Sensitive files excluded from git (`.gitignore`) and container builds (`.dockerignore`).

### A03: Injection

**SQL injection** — All database queries use D1 parameterized bindings (`.bind()`). No string concatenation in SQL.

**XSS (Cross-Site Scripting)** — Three layers of protection:

| Context | Protection | File |
|---------|-----------|------|
| Plain text in HTML | `escHtml()` — encodes `< > & "` | `public/app.js` |
| FTS5 highlight results | `sanitizeHighlight()` — allows only `<mark>` tags, escapes everything else | `public/app.js` |
| URLs in `href` attributes | `safeHref()` — rejects `javascript:`, `data:`, `ftp:` protocols | `public/app.js` |
| HTML attributes | `escAttr()` — encodes `& " ' < >` | `public/app.js` |

**No inline JavaScript** — All event handlers use `data-*` attributes with event delegation (CSP-compatible). Zero `onclick` attributes in HTML.

**FTS5 query sanitization** — Strips `"` from search terms to prevent FTS5 syntax errors that could cause 500 responses.

- `src/index.ts` — `sanitizeFtsQuery()` (line 42)

**CLI JSON injection** — The `recall.sh` CLI uses `jq -n --arg` to safely construct JSON payloads instead of string interpolation.

### A04: Insecure Design

**Input validation on all write endpoints:**

| Field | Limit |
|-------|-------|
| URL | Must be `http://` or `https://`, max 2048 chars |
| Title | Max 500 chars |
| Description | Max 2000 chars |
| Tags | Max 500 chars |
| Import HTML | Max 5 MB |

Invalid URLs (wrong protocol, too long) are rejected with `400`.

**Page parameter validation** — `GET /api/bookmarks?page=` is clamped to `>= 1`. Non-numeric values default to page 1.

### A05: Security Misconfiguration

**Response headers** set on all responses (API via Hono middleware, static files via `public/_headers`):

| Header | Value | Purpose |
|--------|-------|---------|
| `Content-Security-Policy` | `default-src 'none'; script-src 'self'; style-src 'self' 'unsafe-inline'; connect-src 'self'; img-src 'self'; font-src 'self'; base-uri 'self'; form-action 'self'; frame-ancestors 'none'` | Strict CSP, no inline scripts |
| `X-Content-Type-Options` | `nosniff` | Prevent MIME sniffing |
| `X-Frame-Options` | `DENY` | Prevent clickjacking |
| `Strict-Transport-Security` | `max-age=31536000; includeSubDomains` | Force HTTPS |
| `Referrer-Policy` | `strict-origin-when-cross-origin` | Limit referrer leaks |
| `Permissions-Policy` | `camera=(), microphone=(), geolocation=()` | Disable unused browser APIs |
| `X-Permitted-Cross-Domain-Policies` | `none` | Block Flash/PDF cross-domain |
| `Cache-Control` | `private, no-store` | Prevent caching of sensitive API responses |

**CORS** restricted to same-origin and `localhost` (for development). No wildcard `Access-Control-Allow-Origin: *`.

- `src/index.ts` — cors middleware (line 88)

**Generic error responses** — `app.onError` returns `"Internal server error"` to clients, logs details server-side. No stack traces or file paths exposed. Custom `app.notFound` returns JSON instead of framework HTML.

### A06: Vulnerable and Outdated Components

Run the audit script to check:

```bash
./audit.sh
```

This runs `npm audit` (known CVEs) and `npm outdated` (stale versions) inside the container.

**Minimal dependency surface:**

| Package | Type | Purpose |
|---------|------|---------|
| `hono` | Runtime | Web framework (~14KB) |
| `wrangler` | Dev only | Cloudflare CLI |
| `typescript` | Dev only | Type checking |
| `@cloudflare/workers-types` | Dev only | Type definitions |

Only `hono` ships to production. All other packages are dev dependencies.

### A07: Identification and Authentication Failures

- **Timing-safe comparison** prevents key extraction via response timing
- **Rate limiting** (60/min per IP) slows brute-force attempts
- **No default credentials** — `dev.sh` generates a unique UUID key per environment
- **API key required** — server returns `500` if key is not configured (no "open by default")

### A08: Software and Data Integrity Failures

**`.dockerignore`** prevents `.env`, `.dev.vars`, and `wrangler.toml` from being copied into container images.

**Import validation** — Chrome bookmark HTML is parsed with strict regex that only accepts `http://` and `https://` URLs. All imported values are length-truncated before database insertion.

### A09: Security Logging and Monitoring Failures

- `app.onError` logs all unhandled errors via `console.error` (visible in `wrangler tail` and Cloudflare dashboard)
- Rate limit hits return `429` (can be monitored)
- Auth failures return `401` (can be monitored)

On Cloudflare, use **Workers Analytics** and **Logpush** for production monitoring.

### A10: Server-Side Request Forgery (SSRF)

The `POST /api/fetch-meta` endpoint fetches external URLs. Protected by:

1. **Protocol validation** — only `http://` and `https://` allowed
2. **Hostname blocklist** — blocks `localhost`, `127.0.0.1`, `0.0.0.0`, `[::1]`, `169.254.169.254`, `metadata.google.internal`
3. **Private IP range blocking** — `10.x`, `172.16-31.x`, `192.168.x`, `169.254.x`
4. **Internal TLD blocking** — `.internal`, `.local`, `.localhost`
5. **Post-redirect validation** — checks `resp.url` after redirects to catch redirect-based SSRF
6. **Response size limit** — only parses first 512 KB (enough for `<head>` meta tags)
7. **Timeout** — 5-second `AbortSignal` prevents slow-loris attacks

Source: `src/meta-fetcher.ts` — `isAllowedFetchUrl()` (line 17)

## Container Security

The `Containerfile` runs as non-root:

- `USER node` (uid 1000) — the built-in unprivileged user from `node:22-slim`
- All files owned by `node:node` via `COPY --chown`
- Port 8788 (unprivileged, > 1024)

## Files Involved

| File | Security role |
|------|--------------|
| `src/index.ts` | Auth middleware, rate limiting, input validation, security headers, CORS, error handling |
| `src/meta-fetcher.ts` | SSRF protection, response size limits |
| `public/app.js` | XSS prevention (escHtml, sanitizeHighlight, safeHref, escAttr), event delegation |
| `public/_headers` | Security headers for static files on Cloudflare Pages |
| `public/index.html` | No inline scripts (CSP-compatible) |
| `recall.sh` | Safe JSON construction via jq, curl timeouts |
| `Containerfile` | Non-root user, minimal image |
| `.dockerignore` | Excludes secrets from build context |
| `.gitignore` | Excludes secrets from version control |
| `audit.sh` | Dependency vulnerability scanner |
